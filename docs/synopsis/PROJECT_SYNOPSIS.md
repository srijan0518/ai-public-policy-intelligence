# AI-Powered Public Policy Intelligence & Analysis System

This Markdown copy preserves the textual content of the final BSERC project synopsis. The submission-ready DOCX is kept as the local source artifact; this repository copy is intended for GitHub-readable documentation.

## Project synopsis

The project proposes an AI-powered public policy intelligence platform that processes policy documents using NLP, named entity recognition, zero-shot classification, explainable importance scoring, retrieval-augmented generation, policy comparison, and audience-adaptive explanations. The system is designed as an academic decision-support prototype and does not make governmental decisions or provide legal advice.

## Main modules

- Document ingestion and preprocessing
- NLP / NER extraction
- Zero-shot policy-domain classification
- Explainable importance scoring
- FAISS-based retrieval knowledge base
- Grounded RAG question answering
- Policy-version comparison
- Audience-adaptive explanations
- Interactive intelligence dashboard
